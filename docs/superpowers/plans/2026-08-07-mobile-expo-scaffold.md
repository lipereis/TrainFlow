# Mobile Expo Scaffold (Phase 0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a real React Native + Expo app at `apps/mobile` (TypeScript, Expo Router, Clerk Expo SDK, TanStack Query) that authenticates against the existing Clerk instance and proves it can call an existing `apps/web` API route end to end — while preserving the current Capacitor shell, renamed to `apps/mobile-capacitor`, untouched as a fallback.

**Architecture:** Expo Router app with two route groups — `(auth)` for sign-in/sign-up, `(app)` for authenticated screens — gated by a Clerk auth-state redirect in the root layout. A thin `lib/api.ts` fetch wrapper attaches the Clerk session token as a Bearer header and targets the deployed production API (`https://trainflow-chi.vercel.app`) by default. One TanStack Query hook (`useWorkouts`) calls `GET /api/workouts` and renders on a placeholder Home screen — the full round trip this phase exists to prove.

**Tech Stack:** Expo (latest SDK via `create-expo-app`), Expo Router, TypeScript, `@clerk/clerk-expo`, `expo-secure-store`, `@tanstack/react-query`, `jest-expo` for unit tests, pnpm workspaces / Turborepo (existing monorepo tooling).

## Global Constraints

- No direct Supabase/Postgres access from `apps/mobile` — every data operation goes through an existing `apps/web` API route.
- No duplicated backend/business logic — request/response shapes come from `@trainflow/shared-types` where they exist.
- `apps/mobile-capacitor` (renamed from today's `apps/mobile`) must remain intact and buildable — do not delete or break it this phase.
- Dev preview target is Expo Go on a physical device (QR scan) — no simulator/emulator dependency for this phase's verification.
- Default API target is the deployed production API, `https://trainflow-chi.vercel.app`, overridable via `EXPO_PUBLIC_API_URL`.
- Same Clerk instance as `apps/web` — reuse its publishable key, do not create a second Clerk app.
- Trainer/client feature screens (dashboard, clients, workout builder, exercise library, templates, notes, PDF/Excel export, sharing, today's workout, rest timer, progress) are out of scope — this plan only proves the scaffold.

```ts
// apps/mobile/lib/tokenCache.ts
import * as SecureStore from "expo-secure-store";

export const tokenCache = {
  async getToken(key: string): Promise<string | null> {
    try {
      return await SecureStore.getItemAsync(key);
    } catch {
      return null;
    }
  },
  async saveToken(key: string, value: string): Promise<void> {
    try {
      await SecureStore.setItemAsync(key, value);
    } catch {
      // Non-fatal — Clerk will re-prompt sign-in if the cache write fails.
    }
  },
};
```

```tsx
// apps/mobile/app/_layout.tsx
import { ClerkProvider, ClerkLoaded, useAuth } from "@clerk/clerk-expo";
import { QueryClientProvider } from "@tanstack/react-query";
import { Slot, useRouter, useSegments } from "expo-router";
import { useEffect } from "react";
import { tokenCache } from "@/lib/tokenCache";
import { queryClient } from "@/lib/queryClient";

function AuthGate() {
  const { isLoaded, isSignedIn } = useAuth();
  const segments = useSegments();
  const router = useRouter();

  useEffect(() => {
    if (!isLoaded) return;
    const inAuthGroup = segments[0] === "(auth)";
    if (!isSignedIn && !inAuthGroup) {
      router.replace("/(auth)/sign-in");
    } else if (isSignedIn && inAuthGroup) {
      router.replace("/(app)");
    }
  }, [isLoaded, isSignedIn, segments]);

  return <Slot />;
}

export default function RootLayout() {
  const publishableKey = process.env.EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY;
  if (!publishableKey) {
    throw new Error("Missing EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY");
  }
  return (
    <ClerkProvider publishableKey={publishableKey} tokenCache={tokenCache}>
      <ClerkLoaded>
        <QueryClientProvider client={queryClient}>
          <AuthGate />
        </QueryClientProvider>
      </ClerkLoaded>
    </ClerkProvider>
  );
}
```

```tsx
import { useState } from "react";
import { Text, TextInput, Button, View } from "react-native";
import { useSignIn } from "@clerk/clerk-expo";
import { useRouter, Link } from "expo-router";

export default function SignInScreen() {
  const { signIn, setActive, isLoaded } = useSignIn();
  const router = useRouter();
  const [email, setEmail] = useState("");
```

```ts
// apps/mobile/lib/api.ts
const DEFAULT_API_URL = "https://trainflow-chi.vercel.app";

export function getApiUrl(): string {
  const configured = process.env.EXPO_PUBLIC_API_URL;
  return (configured ?? DEFAULT_API_URL).replace(/\/$/, "");
}

export function buildApiRequest(
  path: string,
  token: string | null,
  init: RequestInit = {},
): { url: string; init: RequestInit } {
  const url = `${getApiUrl()}${path.startsWith("/") ? path : `/${path}`}`;
  const headers = new Headers(init.headers);
  headers.set("Accept", "application/json");
  if (token) {
    headers.set("Authorization", `Bearer ${token}`);
  }
  return { url, init: { ...init, headers } };
}

export async function apiFetch<T>(
  path: string,
  token: string | null,
  init?: RequestInit,
): Promise<T> {
  const { url, init: requestInit } = buildApiRequest(path, token, init);
  const res = await fetch(url, requestInit);
  if (!res.ok) {
    throw new Error(`API ${path} failed: ${res.status}`);
  }
  return (await res.json()) as T;
}
```

**Interfaces:**

- [ ] **Step 1: The query hook**

`apps/web`'s `@trainflow/shared-types` package currently exports only request-input schemas for workouts (`createWorkoutSchema`, etc.), not a response/list shape — the list response type is inferred server-side from Prisma and isn't shared yet. Define a minimal local type for just the fields this screen renders; widening it into a proper shared response schema is a follow-up for a later phase, not required here.

```ts
// apps/mobile/lib/queries/workouts.ts
import { useQuery } from "@tanstack/react-query";
import { useAuth } from "@clerk/clerk-expo";
import { apiFetch } from "@/lib/api";

export type WorkoutSummary = {
  id: string;
  name: string;
  status: "DRAFT" | "ACTIVE" | "ARCHIVED";
};

export function useWorkouts() {
  const { getToken } = useAuth();
  return useQuery({
    queryKey: ["workouts"],
    queryFn: async () => {
      const token = await getToken();
      return apiFetch<WorkoutSummary[]>("/api/workouts", token);
    },
  });
}
```

- [ ] **Step 2: The Home screen**

```tsx
// apps/mobile/app/(app)/index.tsx
import { View, Text, FlatList, ActivityIndicator, Button } from "react-native";
import { useAuth, useUser } from "@clerk/clerk-expo";
import { useRouter } from "expo-router";
import { useWorkouts } from "@/lib/queries/workouts";

export default function HomeScreen() {
  const { signOut } = useAuth();
  const { user } = useUser();
  const router = useRouter();
  const { data, isLoading, error } = useWorkouts();

  return (
    <View style={{ flex: 1, padding: 24, gap: 12 }}>
      <Text style={{ fontSize: 20, fontWeight: "600" }}>
        Hi {user?.firstName ?? user?.primaryEmailAddress?.emailAddress}
      </Text>
      {isLoading ? <ActivityIndicator /> : null}
      {error ? (
        <Text style={{ color: "red" }}>{(error as Error).message}</Text>
      ) : null}
      <FlatList
        data={data ?? []}
        keyExtractor={(item) => item.id}
        renderItem={({ item }) => (
          <Text>
            {item.name} — {item.status}
          </Text>
        )}
        ListEmptyComponent={!isLoading ? <Text>No workouts yet.</Text> : null}
      />
      <Button
        title="Sign out"
        onPress={async () => {
          await signOut();
          router.replace("/(auth)/sign-in");
        }}
      />
    </View>
  );
}
```
