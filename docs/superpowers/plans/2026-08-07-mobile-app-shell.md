# Mobile App Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold a Capacitor-based native app shell (`apps/mobile`) that wraps the live TrainFlow production deployment for iOS and Android, ready for the user to open in Xcode/Android Studio, build, sign, and submit to the App Store and Play Store.

**Architecture:** `apps/mobile` is a new pnpm workspace member with no UI code of its own — `capacitor.config.ts` points `server.url` at `https://trainflow-chi.vercel.app`, so both native shells load the live site in a native WebView at runtime. Brand icon/splash assets are generated once from the existing kettlebell mark (`apps/web/public/favicon.png`), upscaled and composited onto the app's own near-black background color, then fed through `@capacitor/assets`' Easy Mode generator to produce every required per-platform size automatically.

**Tech Stack:** Capacitor 8 (`@capacitor/core`, `@capacitor/cli`, `@capacitor/ios`, `@capacitor/android`), `@capacitor/assets` 3 for icon/splash generation, `sharp` (already present in the root `node_modules`, pinned via the root `package.json` `pnpm.overrides`) for the one-time source-image upscale.

## Global Constraints

- No changes to `apps/web`, Prisma, Clerk, or any backend logic — this plan only adds `apps/mobile`.
- App identity is locked: `appId: "com.trainflow.app"`, `appName: "TrainFlow"` — do not use placeholder values.
- `server.url` must be exactly `https://trainflow-chi.vercel.app` (confirmed live, HTTP 200) — this is a remote-content wrapper, not a static bundle.
- No native plugins, push notifications, or offline mode in this pass — pure web-wrapper.
- Icon/splash background color is `#0c0e0d` (the app's own `--background` dark token, HSL `150 8% 5%`, converted to hex) — use this exact value, not an approximation, so the app icon matches the product's actual dark background.
- This build environment (Windows, no Xcode, no Android SDK) cannot compile, run, or launch either native app. Every task's "verification" is limited to file/structure/config checks — do not attempt to open a simulator, emulator, or run a build; that is out of reach here and is explicitly the user's job on their own machine.
- `pnpm-workspace.yaml` already globs `apps/*` — do NOT edit it; `apps/mobile` is picked up automatically.

| File | Responsibility |
|---|---|
| `apps/mobile/package.json` | Workspace member manifest: Capacitor CLI + platform + assets-generator dependencies |

No files outside `apps/mobile/` are created or modified.

### Task 2: Generate the high-resolution icon source

**Files:**
- Create: `apps/mobile/assets/logo.png`

**Interfaces:**
- Consumes: `apps/web/src/app/globals.css`'s `--background` dark-scope value has already been converted to `#0c0e0d` (documented in Global Constraints above — do not recompute, use this exact value in Task 3's flags).
- Consumes: `apps/web/public/favicon.png` (existing 260×260 transparent-background kettlebell mark) — read-only, not modified.
- Produces: `apps/mobile/assets/logo.png`, a 1536×1536 PNG with alpha channel preserved (transparent background, not yet composited onto any background color — that happens in Task 4 via `@capacitor/assets`' background-color flags, which is why this file must keep its transparency).

- [ ] **Step 1: Run the upscale**

From the repo root, run:

```bash
node -e "
const sharp = require('sharp');
sharp('apps/web/public/favicon.png')
  .resize(1536, 1536, { kernel: sharp.kernel.lanczos3 })
  .png()
  .toFile('apps/mobile/assets/logo.png')
  .then(info => console.log(JSON.stringify(info)));
"
```

Expected: prints a JSON object with `"width":1536,"height":1536"`, and `apps/mobile/assets/logo.png` exists afterward.

- [ ] **Step 2: Verify the output preserved transparency and is the correct size**

```bash
node -e "
const sharp = require('sharp');
sharp('apps/mobile/assets/logo.png').metadata().then(m => {
  console.log(JSON.stringify({ width: m.width, height: m.height, hasAlpha: m.hasAlpha, channels: m.channels }));
});
"
```

Expected: `{"width":1536,"height":1536,"hasAlpha":true,"channels":4}`. If `hasAlpha` is `false`, the resize dropped the alpha channel — stop and report BLOCKED rather than proceeding to Task 3, since Task 4's background-color compositing depends on this file having real transparency.

- [ ] **Step 3: Commit**

```bash
git add apps/mobile/assets/logo.png
git commit -m "feat: add high-resolution mobile app icon source"
```

Capacitor wrapper around the production deployment (`https://trainflow-chi.vercel.app`). No native code — this is a WebView shell, so any change to the live site appears in the app immediately with no rebuild needed.
